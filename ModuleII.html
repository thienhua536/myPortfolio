1. What is CSS used for?

CSS is used for styling website, make it prettier, control the visual appearance, layout, and formatting of web pages.

2. What is the difference between inline, internal and external CSS?.

Inline CSS is added directly inside a single HTML tag using the style attribute and only affects that one element. Internal CSS is written inside \style\ tags in the \head\ section to style a single webpage. External CSS is kept in a separate .css file linked via a \link\ tag, allowing one stylesheet to control the look of an entire multi-page website.

3. What are the four parts of the CSS box model?

I. Content: The innermost area where your actual text, images, or other media appear. Its dimensions are controlled by properties like width and height.

II. Padding: The transparent space directly surrounding the content, pushing the border outward. Background colors and background images extend into the padding area.

2

III. Border: The line or frame that wraps around both the padding and the content. You can customize its thickness, style (such as solid or dashed), and color.

IV. Margin: The outermost transparent layer that creates empty space between the element's border and neighboring elements on the page.

4. What is a media query?

A media query is a CSS technique or command that aookues styles only when the device or browser meet the condication of width and height (orientaion)

Media queries (@media) ar the foundation of RESPONSIVE WEB DESIGN, allowing the website to adapt its layout and appearnce across any devive.

5. Why is responsive design important?

Because it ensures a website look good, function properly and provides an optimal user experience across ay device or screen size
